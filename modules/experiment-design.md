# Experiment Design Module

Translates hypotheses into complete test layouts.

## Components of Design

- **Control vs Variant setup**: Explicit configurations of copy, target, or feature.
- **Allocation Rules**: Group selection rules (e.g. 50/50 split of 200 accounts).
- **Taxonomy Validation**: Ensures the design matches properties of the specified experiment type (e.g. Messaging, Pricing).
- **Execution variables mapping**: Document independent variables (changed components) vs dependent variables (metric outputs).
